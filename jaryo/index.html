3그림 요청문

Canva 「Magic Media」 → 「이미지」 → 비율 「가로형」에 붙여 넣어요. 실제로 위 그림을 만든 문장 그대로예요.

요청문 파일 받기(.txt)
  1. 표지

    어린이 그림책 표지 그림. 작은 주황색 여우가 파란 장화를 신고 커다란 노란 우산을 들고 비 오는 숲길에 서 있다. 부드러운 수채화, 따뜻한 색, 단순한 형태, 위쪽에 제목을 넣을 빈 공간. 글자 없음.

  2. 1장면

    어린이 그림책 삽화. 작은 주황색 여우가 파란 장화를 신고 노란 우산을 쓰고 비 오는 아침 마을 길을 걸어간다. 멀리 작은 학교가 보인다. 부드러운 수채화, 따뜻한 색, 단순한 형태, 아래쪽에 문장을 넣을 빈 공간. 글자 없음.

  3. 2장면

    어린이 그림책 삽화. 작은 주황색 여우가 파란 장화를 신고 우산 없이 빈손으로 길에 서서 깜짝 놀란 표정을 짓는다. 비가 조금 내린다. 저녁 무렵 마을 길. 부드러운 수채화, 따뜻한 색, 단순한 형태, 아래쪽에 문장을 넣을 빈 공간. 글자 없음.
    참고: “저녁 무렵” 때문에 다른 쪽보다 색이 진해졌어요. 책 전체 색을 맞추려면 이 낱말을 빼고 넣어요.

  4. 3장면

    어린이 그림책 삽화. 작은 주황색 여우가 파란 장화를 신고 비 오는 숲길에서 하얀 토끼와 갈색 다람쥐에게 무언가를 묻는다. 토끼와 다람쥐는 고개를 저으며 모른다고 한다. 부드러운 수채화, 따뜻한 색, 단순한 형태, 아래쪽에 문장을 넣을 빈 공간. 글자 없음.

  5. 4장면

    어린이 그림책 삽화. 풀숲 아래에 펼쳐진 노란 우산이 있고, 우산 밑에서 작은 달팽이가 비를 피하고 있다. 옆에서 작은 주황색 여우가 파란 장화를 신고 놀라서 바라본다. 부드러운 수채화, 따뜻한 색, 단순한 형태, 아래쪽에 문장을 넣을 빈 공간. 글자 없음.

  6. 5장면

    어린이 그림책 삽화. 작은 달팽이가 작은 주황색 여우의 어깨 위에 올라타 있고, 파란 장화를 신은 여우가 노란 우산 하나를 쓰고 웃으며 비 오는 숲길을 걸어간다. 둘 다 우산 아래에 있다. 부드러운 수채화, 따뜻한 색, 단순한 형태, 아래쪽에 문장을 넣을 빈 공간. 글자 없음.

그림체 바꾸기

요청문의 “부드러운 수채화, 따뜻한 색”만 아래 문장으로 바꿔요. 한 권 안에서는 같은 문장을 써요.

수채화(오늘 책)

부드러운 수채화, 따뜻한 색

색연필

색연필로 그린 그림, 연필 선이 보이는 따뜻한 질감

크레파스

크레파스로 그린 그림, 아이가 그린 듯한 거친 질감

종이 콜라주

색종이를 오려 붙인 콜라주, 종이 결이 보이는 질감

3D 점토

점토로 빚은 3D 인형 장면, 부드럽고 둥근 느낌

판화

판화(리놀륨 판화) 느낌, 굵은 선과 무늬, 색은 세네 가지

색연필 (영어)

Colored pencil drawing, visible pencil strokes, warm texture

판화 (영어)

Linocut print style, bold lines and patterns, limited palette of three or four colors

그림체를 비슷하게 유지하는 4단계

  1. 1

    인물 문장 + 그림체 문장을 매번 그대로 복사해 써요.

  2. 2

    시간·날씨·장소 낱말을 모든 쪽에 같게 써요(“저녁 무렵”을 한 쪽에만 넣으면 색이 달라져요).

  3. 3

    Magic Media 「스타일」을 고른다면 모든 쪽에 같은 것으로.

  4. 4

    Dream Lab → 「+」로 앞 장면 그림을 넣고 「스타일 매치」 → 장면만 설명하면 같은 그림체로 그려요.

같은 인물로 그리려면 모든 요청에 “작은 주황색 여우가 파란 장화를 신고”를 똑같이 넣어요. 그림 속 글자는 이상하게 나오기 쉬워서 끝에 “글자 없음.”을 붙였어요.

4숙련자 코스 · 한 걸음 더

책을 다 만들었거나 Canva를 자주 쓴다면. 슬라이드 8챕터(92~106장)에 실제 화면이 있어요.

8챕터 「한 걸음 더」 바로 열기 ↗
  1. 낭독

    글상자 오른쪽 클릭 → 「Magic Write」 → 「AI 음성 생성」 → 한국어 목소리(민준·유나)

  2. 움직임

    「애니메이션」 → 「Magic Animate」 · 그림 「편집」 → 「이미지로 동영상 생성」 → 「자동」(5초) → MP4로 받기

  3. 번역

    글상자 오른쪽 클릭 → 「텍스트 번역」 → 도착어 「영어」 → 새 쪽 「(영어)」가 생겨요. 결과는 꼭 고쳐 읽어요

  4. 고치기

    그림 「편집」 → 「Magic Edit」 → 전체·영역 지정·요소 → 바꿀 것을 글로 → 「생성」(싫으면 「편집 초기화」)

  5. 크기

    위쪽 「크기 조정」 → 책 표지·홍보 → 「복사 및 크기 조정」(원본은 그대로)

  6. 틀

    「공유」 → 「브랜드 템플릿」 · 이름만 바꿔 여러 장은 「앱」 → 「대량 제작」

Canva 코드 요청문 (누르면 결말이 바뀌는 화면)

홈 왼쪽 「Canva AI」 → 「코드」를 고르고 붙여 넣어요.
